# Muhammed Anwaf — Backend Engineer Portfolio

A personal portfolio focused on backend engineering, system-oriented projects, and full-stack application development.

## Live portfolio

Visit the deployed site: [portfolio-harry-db15.vercel.app](https://portfolio-harry-db15.vercel.app/)

## Highlights

- Backend-focused positioning with Java, Spring Boot, REST APIs, SQL, database management, and deployment work.
- Selected work and an accessible all-projects index.
- Responsive navigation, keyboard focus states, reduced-motion support, and a subtle cursor spotlight for fine-pointer devices.
- A professional profile image and custom AN monogram used across the site and browser tab.

## Built with

- Next.js
- React
- Tailwind CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Validation

```bash
npm run lint
npm run build
```
